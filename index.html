About

Who's behind Brkbeats.

I'm an independent audio plugin developer and music producer based in Austin, Texas. Most of what I build starts the same way: I want a piece of hardware or a workflow tool I can't afford or can't find, so I build it myself — in JUCE, in Swift, in Python — usually improving on the original along the way, since software is a lot easier to iterate on than hardware.

My approach is "master what you own." I'm not interested in chasing gear or building for the sake of building. Every plugin here exists because I needed it in my own sessions first.

Quick Facts

  • Based in Austin, TX
  • JUCE / C++ DSP, Swift, Python
  • Plugins sold as one-time purchases — no subscriptions
  • Formats: Standalone, VST3, AU — Mac & Windows
