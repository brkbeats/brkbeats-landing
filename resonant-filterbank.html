A filterbank that went past the hardware.

Resonant Filterbank started as a hardware recreation and grew into something its own: scatter modulation, tempo-synced stereo LFOs, and a real-time FFT display built right into the interface.

What it does

Multi-band filtering with
real movement.

🎲

Band Scatter Modulation

Randomized per-band movement for filterbank textures that never repeat the same way twice.

🔁

Stereo LFO / Envelope Modes

Independent left/right modulation with host tempo sync, for width and motion that stays musical.

📊

Real FFT Spectrum Analyzer

A shared display shell that switches between spectrum, band, and modulation views as you work.

🎯

Psychoacoustic Resonance Weighting

Per-band resonance is weighted to how the ear actually perceives it, so nothing band feels harsh by accident.

Also Included

Tuned for sound design, not just filtering.

TUNING

Alternate Frequency Sets

Switch the entire filterbank's frequency layout with a single ROOT knob for instant re-tuning.

PRESETS

File-Based Presets

Simple, portable preset files you can save, share, and organize outside the plugin.

SYNC

Host Tempo Sync

Lock modulation rates to your DAW's tempo so everything stays in the pocket.
